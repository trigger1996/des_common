2.3. Basis reachability graph

Definition 2.1 (Ma et al., 2017). Given a Petri net N = (P, T, Pre,
Post), a pair π = (TE, TI) is called a basis partition of T if (1) TI ⊆T,
TE = T \ TI; and (2) the TI-induced subnet is acyclic. The sets TE
and TI are called the set of explicit transitions and the set of implicit
transitions, respectively.

   Note that the acyclicity on the TI-induced subnet is not an
assumption on plants. In fact, one can always subjectively choose
a set TE such that the implicit subset is acyclic — based on which
the BRG-based marking abstraction technique can be used.
