          Abstract: This paper describes DPO-SYNT, a C++ based software toolbox for property
           enforcement in partially-observed Discrete Event Systems. DPO-SYNT implements a recently
           developed uniform framework for synthesizing maximally-permissive supervisors and optimal
            sensor activation policies. It can handle the enforcement/synthesis problems for a large variety
             of properties, including safety, opacity, diagnosability, and detectability, in a uniform manner.

           Keywords: Synthesis Tools, Discrete Event Systems, Partial Observation, Supervisory Control,
           Sensor Activation.
